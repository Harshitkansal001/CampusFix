## ✨ What is CampusFix?

CampusFix is a campus issue reporting app being developed for the **National Institute of Technology Hamirpur**. It gives students and staff one place to report problems such as damaged facilities or maintenance issues, while giving authorized campus staff a scoped queue to review and update reports.

🎯 **The goal is simple:**

> Report a campus issue. Let the right staff review it. Follow its progress.

### Current limits

- Photo uploads are not available yet.
- AI triage and duplicate suggestions are planned; no AI processing worker is implemented.
- Staff provisioning and assignment controls are not available in the app UI yet.
- NIT Hamirpur SSO and a hosted production environment are not configured.

## 🔄 How it works

```text
Reporter signs in
       ↓
Chooses a campus area and describes an issue
       ↓
CampusFix saves the report as New
       ↓
Authorized staff review and update its status
       ↓
Reporter follows the history and in-app updates
```

## 🔐 Data and privacy

Reports are private to the reporter and authorized campus staff. Staff access depends on explicit roles and campus-area membership; an email domain alone does not grant staff privileges.

Never commit `.env.local` or expose a Supabase service-role key in browser-facing configuration. CampusFix is not an emergency service. Campus operations must define urgent-report monitoring and response before launch.

## 🛠️ Run locally

### Requirements

- Node.js 20.9 or newer
- npm
- Docker or another Docker-compatible runtime for local Supabase

### Start the database and app

```bash
npm install
npm run db:start
```

After Supabase starts, run `npx supabase status` and use its local API URL and anon key to create `.env.local`:

```dotenv
NEXT_PUBLIC_SUPABASE_URL=http://127.0.0.1:54321
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=your-local-anon-key
```

Then run:

```bash
npm run dev
```

Open <http://localhost:3000>. Supabase Studio is available at <http://127.0.0.1:54323>; local sign-in emails can be viewed through its email testing service.

### Useful commands

| Command | Purpose |
| --- | --- |
| `npm run dev` | Start the development server |
| `npm run build` | Build the app for production |
| `npm run lint` | Run ESLint |
| `npm test` | Run Vitest tests |
| `npm run test:e2e` | Run Playwright tests |
| `npm run db:start` | Start local Supabase services |
| `npm run db:stop` | Stop local Supabase services |

Install Playwright browsers separately when needed: `npx playwright install`.
